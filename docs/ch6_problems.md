# 第 6 章：拼接成片，找问题

## 目标

把 7 段拼成一圈，对照地图找出问题，并按出问题的环节归类。

## 拼接

`python scripts/stitch_lap.py`（英文版加 `--en`，不要小地图加 `--no-minimap`），输出 `output/dream_circuit_7shots.mp4`，约 57 秒。

- 片头 4 秒（地图和标题）、7 个镜头、片尾 3 秒。相邻段重叠 0.3 秒做交叉淡化，音频同样淡化。
- 每段开头在左下角显示赛段标题卡：名称、弯道、海拔、速度。
- 右下角小地图：红点按 `assets/track_path_7shots.json` 里每个路径点的模拟车速前进，直道快、弯道慢，每段在镜头结束时走完。小地图让画面和地图能逐秒对照，问题一眼就能看出来。

## 成片里的问题

| 位置 | 现象 | 原因在哪一层 |
|---|---|---|
| 镜头 5（约 32–39 秒） | 地图上 T7 右、T8 左，画面里只有一个左弯；小地图红点还在直道上，画面已经入弯 | 分镜：一个镜头里有两次转向；关键帧：K4 远端画成了左弯 |
| 镜头 6（约 39–46 秒） | 下坡直道还没跑完，约第 3 秒突然切到另一个场景，进入 T9 | 分镜：一个镜头里塞了长直道加一个弯 |
| 镜头 1 | K0 远端多画了弯，和地图上的长直道不符 | 关键帧 |
| 镜头 7 结尾 | 终点灯架的样子和起点 K0 不一致 | 关键帧 |
| 所有镜头 | 早期每个镜头的两个候选几乎一样，等于只有一个可选 | 提示词：候选之间只差末尾空格，现在改成 `Take N.` |
| 拼接处 | 按请求时长截断时，接缝会跳 | 拼接：现在按实际时长拼接 |

## 四层归类

出了问题，先判断它属于哪一层，再回到那一层修。四层正好对应第 3 到 6 章：

1. **分镜**（第 3 章）：一个镜头的任务太多（多次转向、直道加弯道）。修法：拆镜头。
2. **关键帧**（第 4 章）：交界画面和地图不符（远端弯的方向不对、多了不该有的弯）。修法：改场景描述，重画关键帧。
3. **提示词**（第 5 章）：动作描述、候选差异、风格。修法：改 `motion` 或 `style`，重拍镜头。
4. **拼接**（本章）：时长、淡化、小地图同步。修法：改 `stitch_lap.py` 或路径数据。

越靠前的层，影响越大：分镜错了，后面怎么改提示词都救不回来。下一章挑最典型的减速弯 T7–T8 来修。
